# GF Gear Batch Generator

**無料評価ベータ v0.5.0-beta.1 / Windows用 Autodesk Fusion Pythonアドイン**

歯数・個数の一覧から7種類の歯車をまとめて作成します。
歯形生成には [GF Gear Generator 1.1.1](https://github.com/CenturySturgeon/GF-Gear-Generator) を使用しています。
独立した追加ツールであり、元作者やAutodeskの公式製品・公認製品ではありません。

## ダウンロード

[v0.5.0-beta.1 の配布ページ](https://github.com/craftvector-dev/GF-Gear-Batch-Generator/releases/tag/v0.5.0-beta.1) の
Assetsから **GF_Gear_Batch-0.5.0-beta.1.zip** をダウンロードしてください。
**Source code (zip / tar.gz) はこの配布案内のアーカイブです。アドイン本体は含みません。**
本体ZIPにはPythonソース、使用説明、BSDライセンスと検証資料を同梱しています。

## できること

- AIに定型CSVを生成させ、回答を貼り付けて複数種類・複数個を一括生成。
- 歯数・個数・名前を一覧入力。行ごとのモジュール、圧力角、歯幅、穴径も指定。
- CSV読み込み（UTF-8 / CP932）、最大200行。
- 独立Componentとして生成し、X方向またはグリッドに配置。
- 同条件の2個目以降を完成ソリッドとして高速コピー。
- 不正行や個別の生成失敗を記録して後続を継続。
- 一括操作のUndo、結果JSONログ。

**平歯車・内歯車・はすば・やまば・内歯はすば・内歯やまば・直線ラックに対応。**
12列CSVで種類を混在できます。[種類別の入力例](GEAR_TYPES.md)を参照してください。
高速コピー側には歯形スケッチ・押出・パターン履歴が付きません。
全個体の歯形スケッチを編集したい場合は高速コピーをオフにします。

## AIの回答から生成する

1. [AI用の定型プロンプト](ai_prompt.txt)をコピーし、末尾の「私の希望」を書き換えて普段使うAIへ送ります。
2. ツールの「AIの回答を貼り付け」→「回答CSV」へ回答を貼り、**「検証して一覧に取り込む」**を押します。
3. 一覧の寸法・種類数・合計個数を確認して**「一括生成」**を押します。

プロンプトはツール画面内にもあります。APIキーは不要です。
全行を検証してから現在の一覧を置き換えます。不正な回答は取り込まず、未取り込みの回答がある場合は生成を止めます。
自然文の直接解釈やAIへの自動送信は行いません。
具体的なCSV例と項目は[貼り付け機能の使い方](AI_TEXT_INPUT.md)を参照してください。

## インストール

1. ZIPを展開し、`GF_Gear_Batch`フォルダー全体を次へコピーします。

   `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\GF_Gear_Batch`

2. フォルダー直下に同名の`.py`と`.manifest`があることを確認します。
3. FusionでShift+Sを押し、`GF_Gear_Batch`を実行します。
4. 履歴をキャプチャする**ハイブリッドデザイン**で`GF Gear Batch`を開きます。

元GFの別途インストールやpipは不要です。
更新時はアドインを停止し、ファイルを上書きしてから再実行してください。
詳しい操作・CSV例・アンインストールはZIP内の`README.md`を参照してください。

## 検証範囲と制限

- v0.5.0をFusion **2705.1.15 / Windows**で検証。公開ZIPのPython実装は検証済みのローカル版と同一です。
- 自動テスト55件、元GFとの216条件の計算配列比較に合格。
- 7種類15個の実形状生成に成功。全幅8mm、独立Component、余白10mm以上、コピーの体積・面数一致を確認。
- 通常画面から混在CSVを取り込み、内歯車1個＋はすば2個＋ラック1個の**4個生成、失敗0**を確認。
  不正入力時の一覧保持・未取り込み時の生成防止もFusionの入力試験で確認。
- 同条件8個の形状比較、独立編集、グリッド余白、11個生成とUndoは旧v0.3.0の検証記録です。
- v0.5.0のFusionプロセス再起動試験、50～100個の実機負荷、Mac・他バージョンは未確認。
  旧v0.1.0の再起動確認を現行版の確認として扱っていません。
- 1回最大1000個は入力上限であり、実機性能の保証ではありません。
- 既存部品・前回のバッチとの重なりは回避しません。
- かさ歯車・ウォーム・斜歯ラック・非標準内歯車・転位・Normal方式、STL・STEP一括出力は未実装です。

検証資料はZIP内の`docs/`にあります。履歴資料は各資料の対象バージョンを確認してください。
ベータのため保存済みデータのコピーで試し、生成形状を確認してください。
